\begin{frame}{What the results add to the literature}
\small
\begin{softbox}[title=Micro-foundation]
Regional brokerage findings become more convincing once we see the mechanism at the inventor level: the effect is not only geographic, it is relational and individual.
\end{softbox}

\vspace{0.15cm}
\begin{softbox}[title=Organization]
Cross-firm brokerage matters, but the richest signal still comes from observing the whole collaboration architecture instead of reducing the network too aggressively.
\end{softbox}

\vspace{0.15cm}
\begin{softbox}[title=History]
The return to brokerage changes over time, which means network advantage should be treated as historically contingent rather than universal.
\end{softbox}

\vspace{0.18cm}
\takeaway{Bottom line: inventors do not innovate in a vacuum. Network position changes the menu of combinations they can realistically imagine and execute.}
\end{frame}
