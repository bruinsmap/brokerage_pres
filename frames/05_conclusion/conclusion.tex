\begin{frame}{Conclusion}
\small
\begin{columns}[T,onlytextwidth]
\column{0.31\textwidth}
\begin{softbox}[title=Finding]
Inventor brokerage is positively associated with the probability of atypical recombination.
\end{softbox}

\column{0.31\textwidth}
\begin{softbox}[title=Qualifier]
The effect survives interfirm and weighted-network tests, but its size changes with the network definition and historical period.
\end{softbox}

\column{0.34\textwidth}
\begin{softbox}[title=Implication]
Innovation policy and strategy should care about who bridges whom, not only about how much R\&D is being produced.
\end{softbox}
\end{columns}

\vspace{0.24cm}

\takeaway{If brokerage changes the opportunity set of knowledge combinations, then network structure is part of the production function of innovation.}
\end{frame}
